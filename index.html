Una plataforma mobile-first
para resolver lo que se rompe.

Plataforma para la gestión de incidencias en instituciones universitarias. Permite reportar problemas y gestionarlos en tiempo real, con trazabilidad completa del flujo.

3 Tipos de usuario
25+ Endpoints REST
4 Capas MVC

La gestión actual está fragmentada.

01

Reporte manual
e informal

WhatsApp, mails, planillas. Se pierde información y no hay estándar para describir problemas.

02

Sin seguimiento
en tiempo real

El alumno reporta y queda en el aire. No sabe quién atiende ni cuánto demora la resolución.

03

Coordinación
ineficiente

No hay forma clara de asignar, derivar o priorizar tareas entre departamentos y equipos de mantenimiento.

04

Sin datos
para gestión

No existen métricas ni historial agregado para tomar decisiones de mantenimiento y mejora continua.

Solución OPERO centraliza todo el flujo: reporte → asignación → seguimiento → resolución

Capas Una request, cinco fronteras.

  • Cliente App Mobile UI nativa, llama HTTP
  • ↓
  • Controller @RestController Recibe HTTP, delega al Service, devuelve JSON
  • ↓
  • Service @Service Lógica de negocio, validaciones, JWT
  • ↓
  • Repository @Repository JPA, queries, transacciones
  • ↓
  • Entity @Entity Mapea tablas de BD
  • ↓
  • Database PostgreSQL Persistencia relacional

Ejemplo POST /api/incidents en vivo. 

POST /api/incidents
→ IncidentController (valida token)
→ IncidentService (valida datos + asigna depto)
→ IncidentRepository (guarda con JPA)
201 Created + JSON
